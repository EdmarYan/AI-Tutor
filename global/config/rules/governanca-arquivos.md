# GOVERNANÇA E MODIFICAÇÃO DE ARQUIVOS

## 1. APROVAÇÃO PRÉVIA PARA ARQUIVOS MARKDOWN (.MD)
Antes de criar, editar ou sobrescrever qualquer arquivo Markdown (`.md`) no sistema (sejam regras locais, regras globais, documentações técnicas ou notas), o agente/assistente DEVE obrigatoriamente:
1. Apresentar ao usuário a proposta exata do conteúdo ou o diff do que será alterado.
2. Informar o caminho completo do arquivo de destino.
3. Aguardar a confirmação explícita do usuário antes de realizar a operação de escrita ou edição.
